## Reproduction

Use a clean checkout of the code revision above, the registry's Python dependencies, the pinned scanner installed with its frozen lock, and local mirrors named `OWNER/REPOSITORY.git` containing the three revisions listed in the JSON. `E2E_ROOT` must name a fresh output directory. Both passes deliberately reuse the same selection and first-round discovery summary.

```bash
E2E_ROOT=/tmp/skillspector-cli-e2e
E2E_SCANNER=/path/to/pinned/SkillSpector/.venv/bin/skillspector
E2E_MIRRORS=/path/to/mirrors
E2E_COMMIT=de0cea99179469b140684e23066957b0a3e5cb13

python3 -m scripts.prepare_skillspector_corpus \
  --selection docs/skillspector/controlled-sources-2026-10-28.json \
  --source-commit "$E2E_COMMIT" --output-dir "$E2E_ROOT/plan"

for E2E_ROUND in 1 2; do
  E2E_PREVIOUS=()
  if [ "$E2E_ROUND" = 2 ]; then
    E2E_PREVIOUS=(--previous-dir "$E2E_ROOT/round-1")
  fi
  python3 -m scripts.skillspector_coverage_v3 scan \
    --selection "$E2E_ROOT/plan/selection.json" \
    --discovery-summary "$E2E_ROOT/plan/coverage.json" \
    --source-commit "$E2E_COMMIT" "${E2E_PREVIOUS[@]}" \
    --scanner "$E2E_SCANNER" --mirror-root "$E2E_MIRRORS" \
    --partition-index 0 --partition-count 1 --maximum-attempts 128 \
    --budget-seconds 2100 --output "$E2E_ROOT/round-$E2E_ROUND-worker.json"
  python3 -m scripts.skillspector_coverage_v3 merge \
    --selection "$E2E_ROOT/plan/selection.json" \
    --discovery-summary "$E2E_ROOT/plan/coverage.json" \
    --source-commit "$E2E_COMMIT" "${E2E_PREVIOUS[@]}" \
    --workers "$E2E_ROOT/round-$E2E_ROUND-worker.json" \
    --output-dir "$E2E_ROOT/round-$E2E_ROUND"
  python3 -m scripts.publish_skillspector_coverage_v3 check \
    --report-dir "$E2E_ROOT/round-$E2E_ROUND" --source-commit "$E2E_COMMIT"
done
```
