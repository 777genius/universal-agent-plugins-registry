Cloudflare

Community package for Cloudflare's 13 platform skills and API MCP server. Build, test, and deploy applications with guidance from cloudflare/skills.

The CLI checks the plugin against your installed agents, selects one compatible source for the complete target set, and shows the exact plan before changing anything.

Automatic detection. The CLI checks this plugin against installed agents, skips incompatible ones, and lets you confirm the targets. ChatGPT is included only when this plugin provides a verified connection.

Clear outcomes. If an agent needs activation or sign-in, the CLI shows the exact next step. It never receives your OAuth credentials.

The CLI plans all selected targets before mutation. Use switch to change source; update and repair stay on the recorded distribution.
